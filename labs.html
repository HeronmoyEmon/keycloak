IK IAM & Keycloak Mastery

Hands-on labs

Every lab in this course runs against infrastructure you stand up yourself — a local Docker Compose stack, or (Part III only) a public test identity server. Nothing in this site talks to a real Keycloak instance; the deployed pages are static, read-only documentation.

Key idea

Parts I-III (chapters 0-18) need no local setup beyond Docker/Java/curl (chapter 0). Part IV (chapter 20 onward) is where Keycloak itself gets installed for the first time, using the environment below.

No repository required

Every lab chapter is fully self-contained: it gives you the complete, real contents of every file it needs (compose files, config, source code) directly on the page, each with a copy button, plus a short "files you'll need" checklist before the first step. You never need this course's own source repository to follow a lab — a blank folder on your own machine and the tools chapter 0 lists (Docker, a JDK, Node, Python, curl) are enough.

Keycloak + PostgreSQL (chapters 20-26, and most later Keycloak chapters)

A Docker Compose stack: Keycloak 26.8.2 (Quarkus distribution, start-dev mode) with a PostgreSQL 17 database. Confirmed working end to end before any chapter was built on it: the stack boots, the Admin Console and Admin REST API both come up, and kcadm.sh (the admin CLI, bundled in the Keycloak image) can log in and create realms/users/roles/clients. Chapter 20 gives you the exact docker-compose.yml to create, with a copy button, and the commands to bring it up.

Chapter 20 creates a single realm, northwind-apps, used as the running example through chapter 26 — each of those chapters' labs starts from a fresh docker compose up rather than one long-lived shared instance, and briefly recreates whatever earlier state it needs so it still makes sense read on its own.

Try it

Before chapter 20, confirm Docker actually works on your machine: docker --version and docker compose version. Chapter 0 covered this already — this is just a reminder now that it actually matters.

More lab environments get added here as later Parts need them: a Spring Boot resource server and a React SPA (Part VI, securing real applications), and Java SPI source examples (Part VIII, extending Keycloak).
